# Calculator
A terminal-based calculator built using Python basics, loops and functions.

Features
- Can do basic arithmetic operations.
- Provides an error message if the user enters an invalid operation.
- Asks the user if he desires to stop the program/calculator.

How it works:
1. Asks you to select your number.
2. Asks you to select your operation.
3. Does the arthimetic operation and prints out the answer.
4. Asks you if you want to quit the program.

How to Run the Script
1. Make sure you have Python 3.x installed on your machine.
2. Clone or download this script to your workspace.
3. Open your terminal or command prompt, navigate to the folder, and run:
